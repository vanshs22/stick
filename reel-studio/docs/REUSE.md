# What was reused from the three zips, and what was decided

| source | what it is | decision |
|---|---|---|
| `faceless-shorts-skill.zip` | a complete three.js production system: SDF clay human, render engine (DOF, bloom, ACES, soft shadows), worlds and props, six styles | **Reused as the 3D engine.** Ported into `remotion-template/src/three/` (`sdf.js`, `human.js`, `engine.js`, `world.js`, `props.js`, `toon.js`) and wrapped in the `Stage3D` component so Remotion stays the only timeline. Its second renderer (headless-Chrome capture) was not kept. Its `selftest`/`setup` pattern informed `scripts/setup.mjs` and `tools/selftest.mjs`. |
| `reel-maker-skill.zip` | one SKILL.md: script rules, 1080x1920 safe zones, scene rules, loudness | **Folded in, not duplicated.** Safe zones live in `engine/tokens.ts` (`SAFE`) and the `safeZones` debug overlay; the scene rules ("topic always on screen", "no empty frames", "show literally what is said", "one idea per scene") are in `skills/storyboard` and `skills/storyboard-critique`; -14 LUFS / -1.5 dB TP is `tools/qa/final_qa.mjs`; the script shape (hook, stakes, steps, objections, proof, CTA) is in `skills/script-writing`. Its "no music in the render" advice is NOT adopted: the toolkit mixes a quiet bed, and the user can set music to none (`audio-plan.json`). |
| `animated-reels (1).zip` | a Remotion template: `primitives`, `Captions`, `voTiming`, `theme` | **Compared; ours kept.** Its `Captions.tsx` (51 lines) has one fixed look and a hard-coded y. Ours (`engine/Captions.tsx`) reads presets from `data/captions.json`, takes position/scale/highlight per project, uses the shared safe area and shows a live preview in the gallery. Not adopted: its look (one fixed warm box). `voTiming` is superseded by `tools/timing/build_timeline.mjs` (word anchors from Whisper). Nothing else was copied. |
| the 8 reference videos | measured, never copied | `reference-library/` holds shot analyses (pace, framing, text zones). The new `tools/reference/analyze.py` repeats the same measurement on any video. |
