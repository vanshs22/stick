# Editorial sticker (2d)

Light grey paper, thick-outlined sticker windows, colour-changing sections and a hooded host. Fast tech explainers.

Best for: tool and repo explainers: GitHub pages, terminals, MCP-style diagrams, 'you pay $0' reveals.

## Rules
- Every window is a sticker: 4 px black outline, hard offset shadow, red/grey/white dots.
- The background changes colour per section (paper, dark, red, green, slate): bg per shot.
- Mono HUD row on top: '// 03 - what it does' left, a counter or keyword in the accent colour right.
- Red scribble circles and underlines point at the proof (star count, price, number).
- The host stays bottom-centre and gestures on the key words; headline text is the caption.

## Defaults
Captions `headline`, shots 1.5-3 s, music `upbeat`.
Camera: No camera; layout motion only.
Type: Sans headline, red italic serif accent, mono HUD.
Transitions: cut, slide, wipe
Sound: upbeat bed, pop per card, stamp on verdicts, ding on the comment box

## Components
RepoCard, Terminal, BrowserWindow, ProofCard, Versus, Ledger, ProfileCard, Checklist, CommentBox, BigStat, EndCard

## Pitfalls
- Soft shadows (breaks the sticker look).
- Same background for the whole video.
- Host covering the card.
