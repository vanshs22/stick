# Characters x and y

Cut from the character sheet the project owner supplied (young man in a navy hoodie = **x**, bearded man with glasses in a green shirt = **y**). Seven poses each: neutral, talking, explaining, pointing, thinking, surprised, approval. Made by `tools/characters_extract.py` (transparent background, 2x Lanczos upscale).
Use: `tokens.presenter.character` in a style pack, or per shot `presenter.look.character` ("x" or "y"). `engine/character-map.js` picks the sprite from pose, mood and speech.
The source poses are small (about 200 px wide). For a sharper look at large sizes, replace the PNGs here with higher-resolution cut-outs of the same poses (same file names).
